# vasyapym.github.io

> Tools, toys, and simulations.

Live at [vasyapym.github.io](https://vasyapym.github.io).

Every project has its own code, its own look, and - where it needs a real engine - its own Go or Rust core compiled to WebAssembly.

## Current projects

### Productivity

- [Waste of Tokens](https://vasyapym.github.io/projects/practice-map/) - An archive of AI outputs, a reader which saves the progress.
- [Quicknotes](https://vasyapym.github.io/projects/quicknotes/) - Local-first Markdown notes with instant sync across devices via Firebase.

### Games

- [Cat Runner](https://vasyapym.github.io/projects/kitty-run/) - A pastel endless runner; inspired by both Hello Kitty and Dark Souls.
- [Evening Forest](https://vasyapym.github.io/projects/evening-forest/) - An 8-bit first-person walk through a forest. With AI fox around and just the vibes.

### Everything else

- [Spine](https://vasyapym.github.io/projects/spine/) - Drag, nest, and retune Flexbox and Grid layouts in the browser. Then copy the code - built around Go.
- [Raft Cluster](https://vasyapym.github.io/projects/raft-cluster/) - A consensus simulator; proof of concept with Rust in core
- [Explosion](https://vasyapym.github.io/projects/explosion/) - A paper-lantern moon detonates into 600 shards. And other explosion experiments.
- [Planck to Now](https://vasyapym.github.io/projects/planck-to-now/) - Scrub through cosmic history on a logarithmic time scale.

## The realm

The landing page hides an opt-in, full-screen layer called **the deep**: a dark abyss where every project is a bioluminescent creature, and you find the one you want by steering a warm lantern toward it.
